Streaming homogeneous POSITION records

j2p_stream_positions(space, current_scene_owner, coordinate_seed, tape, events, snapshots, snapshot_count, staging, output, header, final_coordinate_state)

This consumes one immutable profile-v1 model tape and its per-SHP matrix snapshots. It emits one owned homogeneous Q12 position record for every vertex command in an SDK-submitted display list. These are command-order preclip calculations. They are not visible vertices, polygons, emitted draws, world/screen positions or a renderer. Color, lighting, UV, texture banks, topology, clipping, perspective division and rasterization are not outputs. Source/matching credit is zero. SBC NOP support remains excluded by the unchanged upstream profile.

The actual current SceneOwner, seed.owner.scene, tape and every SHP snapshot must agree in full host/ARM9/main namespace, mapping generation, model-set address/length/index, instance, run, matrix, material and attribute generations. The immutable snapshots must be outputs of the sealed snapshot API for that exact tape and explicit entry matrix state/generation. All source mappings and input objects remain live and immutable for the entire call and between an optional query and build. The caller owns synchronization and truthful generation advancement. Forged typed records or reusing obsolete current identities are outside this ownership precondition; this is not authentication of arbitrary serialized records.

The coordinate seed adds nonzero stream_id, seed_id and coordinate_generation labels. The function is stateless between calls and has no external registry of those labels; the caller owns their freshness and any handoff to another model/run. They bind every record/header/final state. The seed's three signed32 storage slots hold signed16 values for known axes. known_axes is a mask0..7; unknown slots must be canonical zero, but that zero is never consumed as a known coordinate. An initial full23/24 establishes all axes from mask0. A partial-first command must find every untouched axis already known or the entire transaction returns-3. BEGIN, END, MAT and SHP boundaries never reset XYZ.

23 consumes two words: signed16 low/high halves of word0 set X/Y; signed16 low half of word1 sets Z. The unused high16 of word1 has no coordinate effect. 24 consumes one word: signed10 fields at bit0/10/20 are multiplied by64, producing signed16 values; top2 bits have no coordinate effect. 25 sets signed16 X/Y and retains Z. 26 sets X/Z and retains Y. 27 sets Y/Z and retains X. Sign extension uses defined fixed-width arithmetic. Each position uses the resulting raw vector [X,Y,Z,4096]. There is no float conversion or extra model/POSSCALE application.

Only submission1 lists are traversed. Source visibility2 and SDK transparency3 references emit no records and do not alter XYZ, known bits or vertex ordinals. The complete snapshot identity is still checked for every reference. Unsupported provider state or an unknown submission enum is a transaction failure, never a skipped-list result. Post-wireframe alpha0 does not independently imply a skip: the upstream SDK decision is authoritative. SHP-before-MAT remains material-invalid/UINT32_MAX upstream and requires no invented material0 or bank for position math.

Every submitted list is parsed directly from the live mapped bytes with exact bounds and this inherited matrix-free table:00:0,20:1,22:1,23:2,24:1,25:1,26:1,27:1,40:1,41:0 parameter words. Known COLOR20, TEXCOORD22, BEGIN40, END41 and list NOP00 have no coordinate/position-matrix effects. Other opcodes, including NORMAL21, VTX_DIFF28 and hidden matrix commands, refuse the transaction even at the end of a list. This does not expand the upstream opcode domain. Skipped lists are not reparsed by this consumer; the upstream producer's complete source validation and the common immutability precondition still apply.

Snapshot matrix indices are0=projection,1=position,2=vector,3=texture. Stored elements use index r*4+c. At the first vertex of each submitted list form C[r,c]=floor(sum_k(P[r,k]*Q[k,c])/4096), with P=position and Q=projection. Then Position[j]=floor(sum_k([X,Y,Z,4096][k]*C[k,j])/4096). Composition is Pos*Proj in this stored convention. It is not reverse order, sequentially rounded vector*Pos then *Proj, or a sum of per-term floors. The position matrix already contains the qualified source local transforms and POSSCALE. Vector/texture matrices are not position inputs.

For each dot, the sum of absolute signed64 products must be <=INT64_MAX. Only then accumulate, floor12 and narrow to signed32. This conservative bound protects every intermediate accumulation even with cancellation. Clip or final-position narrowing failures return-4. Signed16 XYZ plus h4096 and a signed32 clip matrix already bound the final dot's signed64 magnitude, but its signed32 result still needs checking. Negative floor differs from truncation. W can be zero or negative if it fits; no clipping/frustum/division test is imposed. A skipped or vertex-free list never composes matrices or demands known XYZ. Refused overflow cases are port policy, not original undefined-behavior equivalence.

No alpha, primitive-kind, open-primitive, W-sign or TexGen-mode restriction is imposed by this position consumer. A separate newly linked untouched-core reference qualified POSITION independence for actual TexGen0/1/2/3, two explicit matrix seeds, four primitive modes and three shader variants with live packed/parser/executor state. UV states actually differed while positions agreed with independent Python. NORMAL21 was used only as a reference seed operation and is not admitted as a production DL opcode. This proves a scoped position dependency, not correctness of color, lighting, UV or polygon outputs.

Each148-byte record contains the full position owner; source SBC address/offset and event/reference/submission ordinals; shape index/address and display span; packed header-word byte offset, opcode byte slot0..3 and parameter byte offset; opcode; global and per-submission vertex ordinals; resulting XYZ; and Position[4]. Offsets refer directly to the original immutable list, not a normalized/flattened copy. Command order is preserved. Quad-strip relocation in the reference's temporary buffer does not reorder production records or supply topology.

For count-only validation pass null staging/output/final pointers; header is mandatory. The complete source/seed/arithmetic validation returns the count and owner header without advancing the seed. For construction supply distinct J2pPositionBuffer descriptors, typed live aligned arrays with capacities in records, a header and separate final seed object. Nonzero capacities require nonnull arrays; zero capacities require null arrays. A successful zero-record build is allowed with zero-capacity arrays and still returns the unchanged coordinate state. The complete declared byte products must fit uint32.

All writable ranges must be mutually disjoint and disjoint from all inputs, descriptors, guest registry and every mapped region. Sources are bytewise parsed and may be unaligned; owned output and descriptor pointers have their declared C alignment/type. Construction first validates/counts/arithmetic-checks the entire input without touching caller scratch/output, then stages deterministically, then commits output/final state/header. Under the input immutability precondition any refusal preserves all input, staging, output and final/header bytes. Only the first records count is written on success. There is no hidden allocator, persistent cursor or matrix-state advance.

Success is1. Invalid identities, layout, pointers, overlap or source structure return-1; unsupported profiles/providers/opcodes return-2; missing coordinate context returns-3; checked arithmetic returns-4; insufficient capacities or record-byte count overflow return-5. Existing typed tape/snapshot provenance and caller-owned source lifetimes remain required. The reference harness's1536-vertex/64-drain bounds are evidence-domain limits, not production/hardware capacity claims.

Qualification executed original SDK submission helpers, independent Python arithmetic and a separately named untouched pinned-core packed-word observer, plus real Windows Release/Debug code. Android ARM64 API33 was linked with16KiB alignment but not executed on a device. Public copied-source tests use only synthetic buffers and Python standard library. No emulator, original executable implementation or private assets are production dependencies. Hardware timing/backpressure, camera/readback provenance, skinning/billboards, animation, actual scene execution, rendering, device and complete game execution remain unproved.
