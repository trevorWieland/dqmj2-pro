# Backup backend initializer

The measured host ARM span `0x02011194–0x020111F8` is reproduced by `src/mechanics_save/20261029_backend_initialize.c`. The pinned base compiler with `-O2`, space optimization and the recorded complete flags emits the complete 100-byte function, including both literal words. The real pinned linker reproduces every native byte with unchanged declared relocations. The source is ordinary C; no assembly or executable-byte arrays are used.

Reproduce with `python match_mechanics_save_20261029_backend_initialize.py`. The command resolves repository inputs independently of the working directory and writes `evidence/matches/mechanics-save-20261029-backend-initialize.json`.

The independent oracle runs 840 cases and 1,680 native/recompiled executions. Every execution starts a fresh Unicorn machine with explicit registers, flags, synthetic RAM and stack. It requires a real bounded return, checks all 23 native initializer instruction addresses, compares the complete 4 KiB RAM arena and 32 KiB stack, architectural registers, flags, ordered writes and call ordering. Repeated-call protocols include nonzero flags, explicit resets and common-provider changes to the flag.

A nonzero 32-bit flag at `0x020E5500+0x114` returns without clearing the initialization fields or calling providers. On the zero path, the routine sets the flag to one, clears the measured backend/runtime fields, sets the pending word to all ones and invokes common initialization. The previously accepted callback getter installs function address `0x02010EB8` at `0x020E5B20+0x20`; the previously accepted FIFO setup then registers `0x02011414` on channel 14 and clears its measured state word. The oracle executes those two existing C bodies rather than replacing their effects with a host model. They add no function or byte credit to this batch.

Common initialization, FIFO readiness and callback registration remain explicit synthetic platform boundaries. Their controlled writes and caller-saved register/flag clobbering exercise ordering and reload behavior; their native implementations are not executed or credited. These observations do not establish physical device initialization, FIFO timing, IRQ safety, concurrent reentrancy, save-bank chronology or semantic save-byte meanings. The declared void API makes no return-value promise, although the oracle compares the architectural result registers.
