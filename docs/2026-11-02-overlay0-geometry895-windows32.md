Its original `ov000:ARM:0x021DBC18/1884` canonical match still fails. Frozen876/877/881 source and proofs remain unchanged.

Run `python check_ov000_geometry895_windows32_20261102.py`; an absolute script with `python -I -S` also replays from another working directory. The producer copies the complete preferred kernel text and frozen877 wrong-kernel text byte-for-byte into generated build folders. It supplies a new portable header, global-state storage, signed fixed-point division and notification backends. All target function bodies remain unchanged. The extracted native contract pins source identity, corpus size and expected full-contract negative counts without depending on the current mutable spelling of a regenerated native report.
