# Main slot registration width and generation experiments — 2026-10-31

The measured ARM9 main routine at `0x02015C70` has 656 initialized bytes. Its optional word-input draft compiled 596 bytes with 320 matching bytes. Native instructions load the word at `0x020EC36C`; the initial generated declaration was an unsigned-byte array and its unary dereference read one byte. A new unsigned-word view fixes that observed access in this new draft only. It produces 660 bytes with 446 matching bytes.

Native code also reads the byte at `0x020E68A4` once and retains it while writing four fields, then writes its increment. A fresh local generation value preserves this sequence across potentially aliasing stores. Both byte and word local views produce 656 bytes with 635 matching bytes. Natural declaration order improves this to 648 matching bytes. All source variants contain ordinary C; no forced registers, assembly, encoded instructions or post-compilation code edits are used.

The canonical-qualified `mwldarm` link independently rejects the nearest 656-byte unit: 648 matching bytes leave eight differing bytes. The report records each differing instruction word. A separate original-byte ELF made only for disassembly was diagnostic scaffolding and is neither source nor acceptance evidence. The experiment initially could not import pyelftools before its configured dependency bootstrap and also encountered the linker's external-section ELF layout; those inspection failures did not alter the source or linker.

`python replay_main_slot_register_attempts_20261031.py` recreates all 41 distinct variants from a SHA-pinned previously retained input, recompiles them, and repeats the strict genuine-link rejection. The consolidated report is `evidence/attempts/main-slot-register-consolidated-20261031.json`. Earlier intermediate reports remain under the same `main-slot-register-` prefix. Pointer argument views that do not compile remain failed experiments. Source-role meanings, object extents and whole-function behavior are unproved; native execution count and accepted source credit are zero. These experiments do not change any accepted source, preference, registry, or compiler framework.
