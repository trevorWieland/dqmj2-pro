The provider clears its optional output word before looking up the primary action byte. Null output selects a private local word. Primary byte zero returns the supplied value with output zero. Positive primary mode reads saved-record bytes at `86 + primary` and optionally `86 + secondary`; tested modifier zero selects the smaller byte when a secondary mode is present. A native attribute getter and status reader select a BSS classification/coefficient row. Classification one can reset tiers at most four to zero when either feature word is nonzero. Classification zero applies signed truncating division of the wrapped value/coefficient product by 100. Other classifications either preserve the value for metadata low nibble one, or call the original chance routine with limit 100; failed chance with control zero produces zero. Tier seven negates the word unless the metadata/classification path fixed the sign. Finally the selected tier is written to output.

Cases cover classification 0/1/2/255, coefficients 0/1/25/50/100/255, tier boundaries including malformed 255, signed value extremes/overflow, full-word controls/features, chance success/failure and mandatory draws even at zero value or zero chance. An aligned output alias at saved offset `88` clears primary/secondary bytes before the native tier reader; the independent model requires the resulting tier zero. Inactive mode qualifies null/FFFFFFFF actor and target pointers, and null output exercises the private fallback. No unaligned output address is claimed.

The wrapper accepts nine words: value, action, actor, target, control, output pointer, a raw flag, and two feature words. It calls the provider with value/actor/target/action in R0..R3 and control/output/inverted-flag/features in five stack slots. Nonzero flag becomes zero; zero becomes one.
