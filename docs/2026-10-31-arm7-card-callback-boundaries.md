# ARM7 card callback boundary evidence - 2026-10-31

The measured host ARM7 WRAM contains three callable ARM bodies absent from its existing Ghidra function inventory: 038028E4 / 64 bytes, 03802924 / 80 bytes, and 03802974 / 100 bytes. Their instruction sizes are respectively 60, 76 and 96 bytes. Each ends in BX LR followed by one four-byte literal containing MMIO data-register address 040001A2. They are adjacent, four-byte aligned and have no additional gap or alignment padding. This proposes 232 instruction bytes and 12 literal bytes, all already inside the initialized-module denominator. It adds zero source credit and zero denominator bytes.

The first body reads one SPI byte into the destination and advances that pointer; the second writes a source byte, advances the source and reads back a halfword into a stack slot; the third compares a low-byte readback with a source byte, clears a state word and clips an unsigned remaining count above one on mismatch, then advances the source. These are bounded measured transfer contracts. Device timing, backup ownership, storage contents, valid game saves and scene reachability are unproved.

The proof records ten literal identities across measured host ARM7 modules, each local direct branch, the existing mode-qualified direct-branch audit, and a separate aligned-ARM scan. Both scans find no external branch into an interior; the four raw branch hits are local edges. Unknown indirect/global producers and unclassified bytes remain outside that conclusion. No pool is treated as code. Original caller 03802860 executes its real BX r6 at 038028AC, observes ARM entry and receives the real callback return at 038028B0. Supplied callback addresses are explicit synthetic caller arguments, separate from the static original literal producers.

There are 360 actual direct callback returns, 12 actual original transfer-caller returns and 12 separately observed indirect callback returns. Independent complete mapped-memory models cover unsigned counts 0/1/2/FFFFFFFF, full-word state values, matching and mismatching low-byte readbacks, destination/source updates and preserved backing. Readback values are an explicit synthetic SPI contract. Twenty-one mutation/entry/mode/size controls and six cap/pool failures withhold all stopped-run return/state credit. The strict linker refusal for unqualified 03802924 is retained; shared inventory, configuration and ledgers are unchanged.
