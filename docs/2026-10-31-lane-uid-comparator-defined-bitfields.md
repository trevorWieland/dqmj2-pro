## Measured contract and field widths

The proposed signature is `s32 comparator(const u32 *left, const u32 *right)`. It reads the right UID word before the left word. Right zero returns signed -1 immediately, including when both words are zero. Otherwise left zero returns 1. These early exits do not look up the other nonzero UID. Both nonzero UIDs are passed to original `0x02062A10`, which searches 100 records at `0x021BD674`, stride 132, matching the full UID at record `+0x14`. A missing nonzero UID is unsupported; the native routine subsequently dereferences a null lookup result.

The routine passes each record's signed halfword `+0x18` and unsigned byte `+0x1A` to original `0x02044DC4`. The descriptor getter `0x020449D4` reads the table pointer at `0x020F69F0` and uses a measured 100-byte stride. The category calculation uses descriptor halfword `+4` low four bits and the form byte. It wraps the initial sum to a byte before the positive-form division and regrouping. The fixture independently models the truncation-toward-zero division, including the intermediate -1 case. No named biological category or form meaning is inferred here.

Different categories return right category minus left category. Equal categories compare descriptor halfword `+6` low 13 bits, returning right key minus left key. The upper three bits are ignored. `NativeKind` expresses this measured extraction as a 13-bit unsigned-short field; its other bits and tail are opaque. This is a qualified NDS 32-bit pointer/layout view. It is not evidence that every retained raw-word getter prototype elsewhere is already suitable for a 64-bit host.

The raw m2c expression cast the result of a promoted signed left shift to unsigned. Casting after that shift cannot prevent signed overflow.
