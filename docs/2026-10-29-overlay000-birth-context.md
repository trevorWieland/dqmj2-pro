# Native birth, RNG and synthesis context — 2026-10-29

This writeup separates measured native behavior from application hypotheses. Its namespace is private ROM B2JJ, SHA-256 `674c5cbf3e03e1f8777d39c7bb9bb195e4a625ae278ee307176a0f60d9d38ba6`. Ov000 is the 364,160-byte decompressed module at 021D7240, SHA-256 `783cb72f0d6ee2fdb632aba3e0ae41a9eee0c7e41933192b1680152e50aa61f6`. Its overlapping address range must not be interpreted through ov001 or another overlay.

`evidence/application/ov000-birth-context-20261029.json` records module-qualified configured boundaries, modes, native span hashes, generated disassembly hashes, direct references and independently decoded incoming ARM BL instructions. The generated disassembly is scaffolding. `evidence/application/ov000-birth-rng-20261029.json` separately records bounded native and freshly compiled/linked C executions. Application Python and TypeScript were read as source files; they were neither imported nor edited. Their hashes are in the static report.

Reproduce from any working directory using the repository-local script paths:

python verify_ov000_birth_rng_20261029.py

Its native helper closure includes actual main RNG, division, item and species routines. There are no host callee stubs. Every execution gets a fresh machine, explicit synthetic seed and randomized private context/parents/stack/registers. It must return within 10,000 instructions. Unexpected writes or execution outside the native closure fail.

Main ARM 0203D294/72 updates word 020F6044 using `(state * 41C64E6D + 3039) modulo 2^32`. It stores the new state even when the signed limit is zero or negative. Positive limits return `(state >> 16) % limit`; other limits return zero. Getter 0203D2DC/16 returns the word; swap setter 0203D2EC/24 returns the previous word. These routines already have accepted C. The live BSS word is outside the initialized 930,560-byte main image and the application's larger 961,560-byte ARM9 representation. Neither supplies its current value.

The only configured direct initializer caller is main 02026F00 inside 02026EC0/176, among subsystem initialization calls. Initializer 0203D25C/56 obtains two stack buffers through 0200F3E0 and 0200F48C, then calls 0200FC74 and stores R0. The first two start distinct asynchronous operations through state 020E5438 and wait through 0200FB48 on successful setup. The pure conversion chain validates year/month/day/weekday fields, converts to a day count, multiplies by 86,400, and adds hour/minute/second conversion. This supports a date/time-derived initialization interpretation. Hardware callbacks, clock timing and failure paths were not executed here. The initializer does not check both status returns before conversion.

Reseeding has several distinct contexts. Main 02043718/132 and 02043844/96, plus ov001 021DE598/172, conditionally load the seed from main context 020F69C4+0C when mode byte +24 equals 2. In 02043718 the stored seed is first obtained through main 02065620 from word 021C0EF4+4, then written by 02044564. Main 02065608 is that secondary word's swap setter. Ov006 021D9F5C snapshots the live RNG through 0203D2DC then 02065608; ITCM also supplies a seed through 01FFA8C8. That ITCM helper reads 021CEBE0+8; 01FFA8B8 sets it. Ov001 0220225C/160 stores the live RNG at battle-context 02239D04+18. This is a measured transient snapshot. No complete proof that the live or secondary RNG word is serialized into the save, or that all indirect copies are absent, is claimed. Current scene RNG cannot be recovered merely by choosing a seed in a native adapter.

The native birth stages have stronger side effects than the application's informal “child getter” name suggests:

| Qualified ARM entry | Measured role |
| --- | --- |
| ov000 02229100 / 1644 | Prepare global child record 022474C8, inherited stats, generation, plus, flags and skill points. No direct RNG call and no polarity-byte write occurs in this body. |
| ov000 0222900C / 244 | Resolve parent records, choose polarity, detach parents from active/reserve slots, remove both parents and allocate/commit the child. Returns the new physical creation ID. |
| ov000 0222976C / 240 | Choose polarity using parent equipment, RNG and final species override. |
| ov000 0222985C / 144 | Allocate with 0206271C and populate the new record through native setters. |

For 0222976C the measured call contract is parent-record pointers in R0/R1, child native species ID in R2 and polarity in R0 on return. It stores parent pointers into 02247480+4/+8. It initializes a local selector to 9 on every call. Parent item IDs are bytes at record+31. Main 02065D88 selects 88-byte ItemTbl rows through 021C2AB4, and byte row+2A controls the selector. Trait 1 selects polarity 0, trait 2 selects polarity 1. Opposite forcing traits cancel to selector 9; matching forcing traits retain the choice. Other traits leave the selector unforced. Display item names have not been independently validated.

An unforced selector makes a draw with limit 17. Result zero selects polarity 2 and stops. Otherwise a second draw with limit 1024 selects `result & 1`. Forced equipment consumes no draw. The helper stores the chosen value at prepared child+1B, then main 02044D60 reads species-row+4 bit 15 and overrides it to 2 if set. This override happens after any RNG draws. A species forced neutral can therefore still consume one or two draws. The isolated vector matrix covers every item trait value found in the actual 256-row table, both species flag classes and distinct boundary/neutral-draw seeds. Reported fixture seeds are hypothetical; no future gameplay result is inferred.

Ordinary scene preparation is in 0221B624/1244. It obtains parent IDs through 02221344/02221358, extra skill points through 022212F0 and species/variant through 022212B8. It calls inheritance preparation 022298EC before 02229100. Static ov001 021FB214/1352 first conditionally draws limit 20 for stat scaling, then checks extra-skill candidates with limit-100 draws, stopping on the first failed nonzero candidate.
