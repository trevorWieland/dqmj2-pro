# Derived ARM7 input in the source-package audit

Cohort 94 passes the build, twenty module comparisons, regression and exact scaffold-assisted ROM gates. Its first committed-source audit nevertheless failed: `verify_committed_source_closure_20261030.py` treated every registered generator dependency outside tools/deps/inputs as a Git source path. One frozen initializer producer includes `extract/arm7/arm7.bin` in that dependency list. The file is original executable input and is intentionally absent from the committed source tree. The failed receipt remains `cohort94-committed-source-closure-20261030.json`; it is not overwritten or represented as passing.

The physical ARM7 file is independently regenerated without another tool: read the measured ROM header's ARM7 offset at `30` and length at `3C`, then take that exact range. The offset is `98800`, length is 160,048, and SHA-256 is `9F40087972CCB8B89D4CC4BAF8288123E26A479BB43FA68B18A30A59650633A1`. The complete ROM must first match `674C5CBF3E03E1F8777D39C7BB9BB195E4A625AE278EE307176A0F60D9D38BA6`. The extracted file, registered dependency hash and direct ROM slice are byte-identical.

`verify_committed_source_inputs_20261031.py --cohort 94` performs a separate, narrower classification audit. It recognizes only that exact path/hash/ROM-header slice as derived executable input, checks its host ARM7 report namespace, and records zero source/assembly credit. Every other registered repository path and source-preference dependency is compared byte-for-byte with the selected Git commit. Tools, dependencies and private inputs retain their explicit copied-input category. There is no wildcard exemption for extract directories or executable files.

The companion audit verifies 10,138 committed repository paths and 112 explicit copied dependencies, with no missing or changed source paths. The original verifier, producer, registry, source files, objects and build inputs remain unchanged. No original executable file is added to Git or counted as reconstructed source. The separate oracle closure verifies 217 oracle records and 13,362 committed source/evidence paths.

This repairs packaging evidence, not the decompilation or full clean-build proof. The current complete source-only ROM, full Windows game and Android execution remain unproved. Checkout Z is a separate immutable cohort-90 full-suite run and must be judged only from its own eventual terminal result. Receipt generation and input classification cannot replace that execution.
