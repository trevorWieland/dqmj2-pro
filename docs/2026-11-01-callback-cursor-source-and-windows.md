# Callback cursor source and native Windows execution - 2026-11-01

Main ARM 0200A81C/192 has a typed ordinary C candidate. It sets state bit 0x200 before a four-word operation call. Results 0/1 clear that bit. Result 6 disables interrupts, waits while the bit remains set, restores the original interrupt state and reloads a status through the live result pointer. Every returning path increments the live cursor offset modulo 2^32, including failed operations. Callback and wait services can change that offset and result record. The observed names and prefix views do not establish historical public API names or complete aggregate extents.

All 192 own and 44 IRQ instruction bytes are observed. The operation and sleep providers are explicit supported boundaries; real callback implementations, scheduler/concurrency and malformed pointers remain unqualified.
