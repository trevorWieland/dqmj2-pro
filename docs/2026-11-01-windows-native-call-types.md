# Windows native call type catalogue - 2026-11-01

`python catalogue_windows_native_call_types111_20261101.py` runs six isolated Clang subprocesses over the8,375 successful source111 native units. Each source/object identity is verified before parsing. All8,375 ASTs parse and contain every measured COFF function definition. The catalogue records23,826 direct call sites,167 indirect call sites, visible function declarations, parameter/result types, typedef expansions and function-address references. Original ARM sources and native object bodies are untouched.

The catalogue uses the existing selected-body variants for247 source units. It deliberately retains the pre-deduplication shared-data metadata because that later variant changes no function body. No symbol aliases or C prototype corrections are applied. The AST is evidence of what these compilation units declare and pass; it does not prove that separate units agree or that the declaration recovers the original public API.

`python measure_windows_qualified_alias_candidates111_20261101.py` compares host ARM9 aliases against native-qualified ARM relocation targets and unique selected C definitions. Primitive types must agree after typedef expansion. Fixed prototypes require identical parameters. Unprototyped declarations require complete direct-call arity/promoted-type evidence and no function-pointer escape. Corresponding signed/unsigned exceptions are limited to observed integer literals representable in both types. Opaque aggregate layouts, differing return types, ambiguous overlay targets and incomplete bindings remain unresolved.

All candidates remain measurements until an actual linker trial and appropriate runtime/ABI checks pass. Child programs and ARM7 namespaces are not rebound into host ARM9. No fake definitions, stubs, implicit signature repairs, new source-byte credit or full Windows game execution is claimed. The initial conservative scalar-normalization report is preserved separately; word-boundary normalization corrects over-classification of const unsigned types without admitting opaque structures.
