# Native reward return ABI, 2026-10-29

Replay `python prove_reward_return_abi_20261029.py`. The report is `evidence/abi/reward-scalar-returns-20261029.json`. It records the measured ROM/main/overlay1 identities, native boundaries, original-body hashes, asset hashes, fresh machine states and543 actual returns. These ABI/dependency probes receive zero reconstructed-source credit and do not edit accepted interfaces.

Six main ARM growth-index getters02044A14,02044A58,02044A9C,02044AE0,02044B24,02044B68 return clean bytes in R0. Each has64 independent original-native probes across species, level-tier boundaries, variants and high-bit variant words. The independent model reads the measured EnmyKindTbl.bin row and the appropriate four-byte tier group. Variant addition/subtraction cancels in these routines. The report also validates each body's sole return preceded by AND R0,R0,FF, proving zero extension independently of the sampled data range.

Overlay1 ARM021E404C scales its signed word input by the valid variant0/1/2 factors1,3/2,2, using wrapped32-bit multiplication and signed truncating division, then sign-extends the low16 bits. Thirty-three direct probes include negative values, signed extrema and multiplication wrap. Native ARM021E409C has the same signed16 representation at its sole terminal ASR16/return; its separately frozen504-vector direct execution proof remains the behavioral reference. Neither should inherit unsigned arithmetic merely because a draft context used a generic u32 return.

Overlay1 ARM021E4120 has96 independent six-stat probes with original native species lookup, tiered growth-index lookup, ability bytes, size scaling, variant scaling and parent contributions. Each signed16 destination first receives base growth, narrows, then receives the parent contribution and narrows again. Its return is the full final addition before the last store narrows to16 bits. Eighty-four vectors return a value above32767 while storing its negative signed16 representation. A signed16 temporary would change R0 and is therefore an ABI error, even where ordinary low-valued game inputs hide it.

Overlay1 ARM021E4500 has30 direct probes around the9999 point guard, including malformed synthetic over-cap points/deltas. On the clamp path it returns the full adjustment and stores its low16 bits. For example, points32767 with delta minus32768 produces full R0 minus55536 and a stored signed16 delta10000, while points clamp to9999. Narrowing the return to the stored representation is incorrect. At/below the guard it leaves those fields unchanged and returns the final native stat-cap result.

The six-stat model derives its numeric inputs from measured EnmyKindTbl.bin and AbilityTbl.bin. It independently checks the delta accumulator and return, including signed16 wrap; it does not assign broader gameplay meaning to every stat field or certify all cap/trait combinations. The cap probes use variant0 with zero base stats so that the point adjustment is isolated while original cap callees still execute. Whole mapped RAM, complete stack, preserved registers, flags and ordered traces are retained. No gameplay stubs, filesystem bindings or hardware substitutions execute.

The992-byte growth source is still unmatched. These facts may guide new unmatched drafts; all accepted sources and prototypes remain frozen.
