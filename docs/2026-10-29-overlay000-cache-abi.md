The source hashes, exact compiler/archive/linker identities, flags, relocations, typed bindings and frozen link artifacts are in the reports. All source is comment-free C, with no executable arrays, assembly or opcode patching. Existing accepted source and proofs remain unchanged.

These callers use the independently measured cache APIs described in `evidence/abi/main-cache-sdk-20261029.json`: main `02048404` returns index 0..7 or full-word 000000FF; main `0204854C` consumes the bank in R0 and the full record index in R1, returning an eight-byte lease pointer or zero. The lease has a flags word and a pointer to a 100-byte cached record. Recovering the missing R1 argument removed an actual dataflow omission in older drafts.

The 320-byte caller also requires six arguments to main `0204B4F4`. Its native prologue reserves 24 bytes, reads incoming stack slots at `0204B4FC` and `0204B508`, and forwards R3 to `0204B1C4`, where that value is saved at `0204B1D4` and stored as a byte at `0204B200`. The existing exact ITCM `01FFA988` caller independently supplies six arguments. The old draft omitted one repeated argument of value 2. The constructor report records the complete 72-byte callee hash and this static ABI evidence; it does not claim dynamic execution of that rendering path.

Each of the five new callers has 45 vectors/90 executions, totaling 225 vectors/450 native-versus-linked runs. They execute actual native SDK cache lookup, string comparison, exhausted lease scanning and close/clear routines. Every machine starts independently with deterministic randomized registers, flags, manager bytes, cache flags and stack bytes. No host callee stubs are installed. All eight cached-name indices and the full-cache/255 path are tested. The independent model checks the byte handle store, zero lease store, selected cached-record clearing, untouched state and complete RAM. Native/source comparisons additionally cover R0-R12, CPSR, scratch/stack memory and instruction/write traces; PC must reach the real return sentinel with SP and preserved registers restored within 30,000 instructions.

Fixtures use null cached backing pointers so the real native close path avoids heap frees. Allocation/rendering success, cache-miss filesystem loading, non-null backing frees, malformed pointers and physical hardware contexts remain unsupported.
