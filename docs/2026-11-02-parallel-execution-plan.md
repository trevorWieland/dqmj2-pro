## Packet contract

Each packet records base commit and input/tool hashes; canonical identities and full code/pool extents; exclusive paths and permitted edits; frozen ABI/types/globals/relocations; reproduction argv and fixture closure; negative attempts; unsupported behavior; proposed credit and acceptance criteria.

Coordinator intake uses the established common READY schema: `status: ready-for-coordinator-acceptance`, `romSha256`, `packets` with `report` and producer argv, full `identities`, immutable `files`, and optional pinned `canonicalDescriptor`. See the [host ARM7 example](../evidence/lanes/parallel-wave20261102/host-arm7-seventh/ready.json). Worker reports are refreshable pre-seal outputs; runtime sources/tools/inputs remain immutable. Preserve unselected research inventories as explicit diagnostic lineage rather than compiler-input declarations.

Start with approximately 5–20 KiB of opportunity, adjusted for coupling and measured throughput. This is a sizing experiment, not a delivery promise. Strongly connected routines and shared-state families stay together. If necessary, deliver an independently closed subset and explicitly retain the blocked remainder.

Workers may add unique source/scripts/evidence in their assigned paths. They do not edit shared registries, source preferences, manifest, global ledger, accepted sources or shared build outputs. Shared interface changes are proposals to the coordinator. They do not run shared-root integration/cohort publication or global checks. Inputs consumed by active shared validation remain frozen.

Use existing pinned compilers and genuine linking. No ordinary-logic assembly, binary scaffolding, instruction/register/object/relocation patching or generated draft receives source credit. README source policy remains no authored comments and at most 500 physical lines per authored code file.

## Matching and tooling strategy

Check measured word/byte widths, signedness, raw call boundaries and control-flow shape before long register-allocation searches. Bound unresolved layout work and hand off the exact blocker. Preflight every private negative-control compile path under a short Windows output root before running a long fixture batch.

Classify mismatches before broad search: boundary/pool; ABI/type width; compiler profile; translation-unit/inlining context; control flow; register lifetime; final link/layout. Reuse accepted neighboring patterns and retain rejected experiments in searchable local receipts.

Use dsd/objdiff for structural feedback and Ghidra headless/m2c for hypotheses. Existing original images and independent fixtures provide comparisons. Qualify decomp-permuter or ndspy only for a measured bottleneck. Use CLI/Python/JSON tooling; no MCP infrastructure is needed. Preserve the working Windows toolchain and all frozen historical producers.

New orchestration uses stable entrypoints around pinned producers rather than another series of versioned coordinator replacements. Emulator work still requires demonstrated need plus silent/disposable-state isolation.
