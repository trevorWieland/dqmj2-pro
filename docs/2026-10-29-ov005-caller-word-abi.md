# Overlay 5 caller word ABI recovery, 2026-10-29

The private measured ROM remains SHA-256 `674c5cbf3e03e1f8777d39c7bb9bb195e4a625ae278ee307176a0f60d9d38ba6`. This covers ov005:ARM 021D761C..021D773C (288B) and 021D7E58..021D7EE0 (136B). `python match_ov005_call_abi_20261029.py` recompiles both ordinary C files in `src/overlays/`, validates their complete configured spans, really links them with the pinned MW linker, and writes `evidence/matches/ov005-20261029-call-abi.json`.

The broad 91-function draft run initially produced 288 B/284 matching and 136 B/132 matching. Every difference was outside relocations, so link-only recovery correctly rejected both. Instruction comparison exposed missing caller inputs rather than a valid code match. Native 021D75F8 consumes R0 as a context address; the original draft called it without an argument, letting the compiler overwrite R0 during a nearby field store. Explicitly passing the context preserves the native allocation and gives 288/288. Native 021D7874 saves R2 on entry and consumes it on its mode 5 callback path; explicitly passing the observed third word 0 gives 136/136. No fixed-register directive, assembly, executable byte array or postlink patch is used.

The 288 B source also performs its subtract/range test in unsigned 32-bit arithmetic, preserving native wrap without depending on signed C overflow. Self-function-pointer relocation in the 136 B caller is explicitly qualified as its own ARM function, not data. Every external call and data address is qualified to the correct module; module load-address reuse is not an identity.

The independent harness passes 210 cases/420 actual native-or-linked returns: 162 event/argument vectors and 48 null/non-null packet/filter vectors. It covers all switch groups, wrapped/extreme words, full-word truth values, packet halfword edges and early returns. A complete data-RAM model checks only the permitted word/halfword updates; an independent call-word model checks arguments and ordering. Both executions agree on all general registers/CPSR, stack, ordered stores and PC traces, and actually return with balanced stacks.

Callee boundaries are explicit return-only providers. Their original SDK networking/UI/state execution is not certified by this harness. The two callee entry-read witnesses qualify caller word contracts; physical R0 results and byte matching do not prove every historical semantic return declaration or a universally consistent original header. The report freezes source/object/compiler/linker hashes and mode-qualified dependencies. Module/cohort acceptance remains separate from this standalone source and execution proof.
