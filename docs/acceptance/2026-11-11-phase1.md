## 3. Mod surface — `ops/mod_patch.py`

The documented example spec (`docs/modding/example-title.json`) was copied into a scratch directory
together with a copy of the private ROM, so the output image lands in scratch **[private input]**.

```
python ops/mod_patch.py --root <scratch> --spec <scratch>/spec.json --check
python ops/mod_patch.py --root <scratch> --spec <scratch>/spec.json
python ops/mod_patch.py --verify-header <scratch>/build/mods/title/game-title.nds
```

Observed:

```
patch 0  0x00000b  1 B  ok  (ROM title, last character: 'P' -> 'M' …)
checksum   written 0x83a9
header     valid after patch (logo CRC, header CRC, field bounds)
--check: verification passed, nothing written                     (exit 0)

wrote …/build/mods/title/game-title.nds (175959612 bytes)          (exit 0)

header valid: logo CRC ok, header CRC 0x83a9, fields in range      (exit 0)
```

Byte-level confirmation: the patched image differs from the input at **exactly three offsets** —
`0x00000B` (title byte `0x50` → `0x4D`) and `0x00015E`/`0x00015F` (the header CRC16 `0x83A9`).
No other byte changed, so the patch is confined to the documented locations.

**PASS.**

## 5. Platform contract — `docs/platform/contract.md`

Five cited source paths, all present and containing the claimed construct:

| cited path | exists | claimed construct observed |
| --- | --- | --- |
| `src/hardware/main/native_main_hw_02007ff4.s` | yes | symbol `native_main_hw_02007ff4` |
| `src/hardware/bootstrap_bios/native_main_bios_020002ae.s` | yes | `.global native_main_bios_020002ae` with `swi 4` (the `IntrWait` annotation) |
| `src/runtime/runtime03/native_main_02041774.c` | yes | file present as cited |
| `src/itcm/dma.c` | yes | file present as cited |
| `src/runtime/20261101_word_channels/native_main_0200434c.c` | yes | channel-register writer |

The headless-boot blocker list is present as §3 ("What blocks a headless boot today") with six
bullets (KEYINPUT reader, sound API, VRAM/OAM upload, NitroFS mount, `native_fn_020042e0` ABI,
`main` call order).

**Documentation defect found:** the sixth bullet is now **stale** — it says "The reconstructed
`main` at `0x02000c34` is not in matched source yet", but
`src/main/p3g_main_02000c34/native_main_02000c34.c` exists in this same commit (recovered and
merged in #116). The containment list should drop or rewrite that bullet. This is a doc fix, not a
failure of the artifact's structure; it is recorded here rather than silently patched.

**PASS (with the stale-line finding above).**
