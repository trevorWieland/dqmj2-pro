# Variadic byte-formatter context for fresh drafts

`qualified_byte_variadic187_context_20261101.apply(context,spec)` supplies the existing matched `int(u8 *, const u8 *, ...)` view of primary ARM9 main0x0201D444 only when a new generated context has the exact empty `u32 func_0201d444()` declaration. It checks the frozen formatter source SHA-256 and complete native44-byte span, with its declared ARM entry and measured module. Existing typed or explicit-void declarations stay unchanged. ARM7 and alternate-program namespaces are excluded. Primary ARM/Thumb and overlay caller contexts remain eligible because the callee is the same primary ARM9 function. No accepted source or shared catalogue is edited.

Run `python experiment_save_core_variadic_context187_20261101.py`. Its committed baseline assembly/context are generated analysis inputs with zero reconstructed-source credit. It uses the pinned unmodified m2c entry point and records hashes of the inspected ARM ABI and call-translation implementations. Seven namespace/idempotence/preservation checks and two tampered source/native pin controls pass. The baseline and transformed contexts are independently passed through m2c with no cache; output and exact commands are recorded. Invocation from the lane parent with `-I -S` also succeeds.

The concrete caller is main0x02066C64. Its old context declared the formatter without a prototype. Pinned m2c's ARM heuristic discards a speculative argument register if another instruction also uses the value; variadic callees bypass that stricter filter. The name pointer in R2 is also used by the preceding conditional, so the old output omitted it from the `%s.enct` call. With the actual variadic declaration, new output retains the conditional word as the third argument. The separately frozen 272-byte source packet supplies native/compiler/link and returning-call evidence for that explicit forwarding, not new credit from this context helper.

Retained variadic registers can also be stale values. Their types and actual format use still require review. In this very test the new byte-pointer formal makes m2c infer `u8 sp7`, a single-byte local, while native remaining stack backing is17 bytes. That scalar is not an adequate formatted-string object. The committed output is an analysis hypothesis, not source ready for adoption. Bounded stack arrays, original declaration uncertainty, format-derived pointer casts, floating word pairs, and native/source returning models remain separate gates. This helper establishes neither arbitrary formatting correctness nor a host/Android `va_list` ABI.
