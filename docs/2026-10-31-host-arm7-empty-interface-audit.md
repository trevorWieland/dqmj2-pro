# Bounded host ARM7 empty-interface audit, 2026-10-31

The new read-only audit freezes a 430-source subset of accepted cohort92 host ARM7 ARM C, including 103 no-input function definitions. It finds no surviving candidates within that explicit subset and stops at every call. This is not evidence that erased arguments are absent from the project. Nonleaf callee input inference, post-call dataflow, source headers containing aliases, Thumb whole-function control flow, ARM9 and arbitrary indirect calls are outside the audit.

Run `audit_host_arm7_empty_interfaces_20261031.py` with the pinned project Python from any working directory. The scope manifest pins every selected C source and the accepted snapshot; extra source files available in another checkout cannot silently enlarge the survey. No signature, shared analyzer or accepted source is edited, and no source or byte credit is granted.

Calibration found a real instrumentation gap: Capstone regs_access and the frozen v3 analyzer omit a register used solely as a register-controlled shift count. Native `037FD10C` reads incoming R0 in `orr r0,r3,r2,lsl r0`, yet the old summary reports input mask0. The new audit explicitly includes register-shift operand reads and records the old and augmented summaries separately. The actual original `037FD34C` callsite `037FD368` then becomes a positive calibration for the old draft's empty extern/call interface; an explicit word argument is no longer a candidate. The newly matched initializer independently executes this callee with R0=1 and checks its state effect.

Fourteen synthetic controls cover callee-save push/pop exclusion, bare-return residue exclusion, consumed pointers, argument definition before use, known callee inputs, stop-at-unknown-call behavior, register versus immediate shifts, and ARM/Thumb operand extraction. Thumb tests cover operand extraction only, not a full Thumb CFG or matching campaign. Two end-to-end calibration checks additionally require detection of the actual D34C/D10C missing-input pattern and rejection of its explicit-argument counterpart. Instruction predicate states are enumerated and invalidated across flag writers; operand-value relations are not solved, so remaining may paths can still be infeasible. Cycles/transitive call outputs and opaque tails are not treated as proven.

Known main ARM9 callers `020CD5BC` and `020CAB98` to `02049AD0` are explicitly excluded by processor/module scope, not scored as negative findings. The initial pre-calibration zero survey was rejected. Its provisional raw JSON was regenerated before the failure was frozen; the attempt receipt preserves its known SHA and the observed calibration failure without claiming historical raw bytes can be recovered. Frozen v3 and all accepted source are unchanged.

Final report SHA-256: `21e960b5d003d18ec719c73db4354430c6fb536d38f0538450deb8fb0e527f54`, identical in the lane and unrelated working directory. The useful new result is a calibrated register-shift read check and a bounded survey with explicit exclusions, not a completeness certificate or an automatically approved signature repair.
