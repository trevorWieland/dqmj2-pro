## Candidate screen

`ledger/functions.jsonl` counts 767 unmatched `ov000` rows, all ARM. A
disassembly screen kept 24-96 byte rows with at most one `bl`/`blx`: 48 leaves and
51 one-call rows. Excluding addresses that already have a `src/` file (the ledger
is stale for `src/ov000/pass1_20261111`: its 39 shipped rows still read
`functionMatched: false`) left 45 candidates. 58 distinct rows were authored; 23
match exactly and the other 35 are parked with their one-line reason below.
`ops/check_duplicate.py` finds no definition of a shipped address outside this
lane.

## What made the rows match

1. **Every global block is an `extern` array plus `M2C_FIELD`.** Accepted
   neighbours (`src/ov000/p2_021d72cc`, `src/runtime/ov000-drafts01`) name the
   block `native_data_ov000_<addr>` and reach fields through
   `M2C_FIELD(block, type *, offset)`. Writing `*(u8 *)(base + off)` lets mwcc fold
   `base + off` into one literal, which the image never contains; on `0x021d9af4`
   the fold also erased a whole `add #0x1000` and turned a 64-byte row into 76.
2. **Declaration order decides the register rotation.** `0x02212480`/`0x022124b4`
   need `s32 result` declared before the lookup call (result in r4, the value
   argument in r5); `0x02223d88`/`0x02223df0`/`0x02223e70` need the outer counter
   declared before the row pointer (counter in r3, base in lr, inner counter in
   ip); `0x021e60a8`/`0x021e61c0` need the order result, table, record.
3. **The image's loop rotation is evidence, not style.** Rows whose compare sits
   after the body are `do`-while in the original (`0x021ef4d8`, `0x02223d88`
   family, `0x021e60e0`, `0x0222b0c8`); a `for` compiles a loop-entry test the
   image does not have.
4. **Argument width is a code shape.** `0x022124e8`/`0x02212518`/`0x02212480`/
   `0x022124b4` take 32-bit coordinates and call a 16-bit-argument lookup: the
   image's `lsl #0x10`/`asr #0x10` pair is the narrowing conversion. Declaring the
   parameters `s16` removes those four instructions.
5. **`switch` is not interchangeable with an if-chain.** `0x02209100` compiles
   from five plain `if` returns with no trailing return (the last test keeps
   `bx lr`), while the same source as a `switch` becomes a jump table; conversely
   `0x021f2764` needs a `switch` with `case 6:` sharing `default:`.
6. **No `-opt speed`.** Every row was accepted under `p001` + 2.0/base, which is
   what 968 of the 1,181 matched `ov000` rows use and what every accepted
   neighbour in the candidate regions carries; the lane rule pins it so the module
   default (`p003`, which adds `-opt speed`) cannot claim the rows.

## Unknowns

Every shipped row states its own unknowns in-source: the meaning of the
`0x02232568`/`0x02232668` record tables and their 16-byte entries; why
`0x02246594`'s stride-3 blocks are 2x3 and cleared in three places; the
`0x0223526c` 0x2cc record's 0x274 state byte; the 0x02236ed8 slot array's 0x27c
stride and 0x278 in-use byte; which state machine the 0x02238510/0x02238514
latches serve; and the request ids 0xe/0xf/0x1e/0x1f/1 passed to the queue
services. Byte identity establishes the code, not the gameplay semantics.
