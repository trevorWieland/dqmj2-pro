# Optional source-word input contexts

The frozen cohort83 selected-source snapshot supplies4,689 parameterized integral/pointer signature views suitable for optional ARM32 word-argument drafting contexts. Sixty-three other parameterized signatures are excluded. This is a catalogue of reconstructed C views, not4,689 newly proved historical prototypes or native input contracts. It adds zero source credit.

Generate with `python source_word_inputs_20261031.py`. The [catalogue](../evidence/verification/source-word-inputs83-20261031.json) pins snapshot/source hashes, build/processor/program/module/mode/address identity, complete parameter text and proposed word-slot count. Ten calibration controls cover empty-prototype filling, preservation of explicit void/typed declarations, unknown targets, wrong processor/program, ambiguous addresses, excluded64-bit/function-pointer inputs and nested parameter parsing.

New unaccepted draft tooling may call `apply_context(context, catalogue, processor='arm9', program='')` after constructing its existing context. The helper returns rewritten context plus an edit ledger. It modifies only empty generated external prototypes. Existing explicit parameter or void declarations are retained. Overlay-qualified symbols remain module-qualified; unresolved/ambiguous addresses are untouched. No frozen decompiler producer, accepted source or current primary selection is edited.

Integral values and pointers become opaque32-bit input slots. No pointer layout, field meaning, original typedef, floating-point interpretation, precise register liveness or valid-object domain is inferred. Scalar floating/64-bit, aggregate/array, function-pointer, variadic and oversized signatures are excluded. The catalogue can help retain incoming arguments that an unknown callee prototype previously lost, but every new C result still requires compiler/linked-byte equality, qualified native behavior and interface review. Stronger measured prototypes such as the two-byte skill input should be installed explicitly and remain intact.

The coordinator generates this catalogue from its complete frozen source snapshot. Worker lanes can consume the copied catalogue without rebuilding it from an incomplete local source subset. Source/callee profiles are hypotheses until validated for each candidate; compiler settings are never generalized by this helper.
